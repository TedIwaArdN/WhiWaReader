# WhiWaReader
Get a list of used Resonators from Wuwa's Share image in Whimpering Waves. 
Run ```WhiWaTokenDownload.py``` to grab token images from [encore.moe](https://encore.moe/)

**Input:** 

```PATH to the shared image (1747 × 983)```

**Output:** 

```a list of 6, contains names of images of Resonators used in WhiWa```

```a list of 2, contains names of images of Tokens used in WhiWa```

**Required Library:** skimage.metrics
```bash
pip install scikit-image
```

**Python version:** 3.11
