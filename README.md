# WhiWaReader
Get a list of used Resonators from Wuwa's Share image in Whimpering Waves. 

**Input:** PATH to the shared image 

----**Image Resolution:** 1747 × 983
**Output:** a list of 6, contains name of images of Resonators used in WhiWa

**Required Library:** skimage.metrics
```bash
pip install scikit-image
```

**Python version:** 3.11
